# Канон: количественное исследование творчества одного автора

Этот документ — рабочая инструкция для модели (или человека), которая строит исследование
вида «Бродский на просвет» для другого автора: поэта или прозаика, русского или нет.
Он собран по итогам проекта о Бродском (этот репозиторий) и описывает:

1. что спросить у заказчика до начала;
2. как собрать и очистить корпус;
3. какие измерения делать и по каким правилам;
4. как проверять себя без ручной разметки;
5. как собрать интерактивный отчёт;
6. какие ошибки уже были и как их не повторить.

Пометки в тексте:

- **[проверено]** — сделано и проверено на Бродском, код есть в этом репозитории;
- **[не проверено]** — разумная рекомендация, на практике ещё не опробована.

Код-образец лежит здесь же: `scrape_brodsky.py`, `merge_sib.py`, `build_epub.py`, `analysis/*.py`,
`analysis/report4.*`. Для нового автора код не копируется целиком: берутся модули и правила,
а куски, привязанные к Бродскому (словари, исправления имён, периоды), пишутся заново.

## 0. Принципы, которые не обсуждаются

1. **Числа только из данных.** Любое число в отчёте получено запросом к корпусу, а не оценено на глаз.
   Если данные недоступны, так и сказать. Если число — нижняя оценка (словарь мог пропустить слова),
   написать это рядом с числом.
2. **Никакой ручной разметки и ручной проверки заказчиком.** Проверка — автоматическая: сверка
   с внешними списками, аудит по сырому тексту, выборочный просмотр контекстов самой моделью.
   Если модель заметила ошибку в контекстах, она правит правило, а не данные по одному случаю.
   Исключение — короткий явный список исправлений (склейка написаний одного имени и т. п.),
   который целиком приведён в методике отчёта.
3. **Читатель не специалист.** Отчёт — развлекательный, но сделанный профессионально.
   Термины заменяются простыми словами, а без которых нельзя (ямб, дольник, рифма) — объясняются
   на примере из самого автора.
4. **Всё, что можно показать графиком, показывается графиком.** Таблица данных — дополнительно,
   под графиком, свёрнутая.
5. **Тяжёлое — только если необходимо.** Без GPU. Новые пакеты ставятся только тогда, когда без них
   нельзя, и по возможности в отдельное окружение.

## 1. Что спросить до начала

Правило проекта: задаётся **один** уточняющий вопрос за раз, только если без ответа нельзя
двигаться. Ниже — список развилок; по каждой есть значение по умолчанию, и спрашивать нужно
только о тех, где умолчание может не подойти.

| Развилка | Умолчание | Почему важно |
|---|---|---|
| Источники текстов | найти сайт с полным собранием + одно печатное собрание в EPUB/FB2 у заказчика | полнота корпуса |
| Язык(и) автора | определить по текстам | выбор морфологии и метрики |
| Сравнивать ли с другими авторами | **нет** (для Бродского заказчик запретил) | меняет половину разделов |
| Жанры в анализе | всё авторское: стихи, проза, пьесы, письма — отдельными подкорпусами | |
| Переводы автора, интервью, тексты о нём | исключить из анализа, но посчитать и назвать | чистота «авторского» |
| Спецтема (у Бродского — Венеция) | спросить, есть ли | отдельный сборник и раздел |
| Периодизация | взять с источника или по биографии, затем проверить алгоритмом (раздел 4.9) | все графики «по периодам» |
| Публиковать ли отчёт с цитатами | спросить перед публикацией | авторское право |

## 2. Корпус

### 2.1 Сбор [проверено]

- Список страниц — из `sitemap.xml`, а не обходом ссылок. Обход проверяется сверкой с картой сайта.
- Каждая страница кешируется на диск (`.html_cache/`, имя — md5 от URL); повторный запуск не ходит в сеть.
- 4 потока, повторы с паузой, журнал пропусков.
- Кодировку определять по байтам: встречается cp1251 внутри utf-8-страниц. Читать байтами,
  декодировать с `errors="replace"`, скрипты и стили удалять до разбора.
- Преобразование HTML → текст для стихов:
  - сырые переводы строк внутри HTML сначала заменить пробелом;
  - потом `<br\b[^>]*>` → `\n` (бывает `<br class="calibre1"/>`), `<p>` → `\n\n`;
  - снять общий отступ.
  Иначе строки стихов склеиваются.
- Для каждого текста сохранить: `url`, `title`, `section` (раздел сайта), `period` (если сайт даёт),
  `source`, `text`. Формат — JSONL, одна запись на текст.

### 2.2 Второй источник и объединение [проверено]

- Печатное собрание (EPUB) разбирается по spine и якорям оглавления (NCX); сноски отделяются.
- Совпадение текстов между источниками — по доле общих 5-словных шинглов:
  больше 0,5 — один и тот же текст.
- Правило выбора версии: берётся источник, где текст полнее; альтернативный перевод оставляется
  отдельно, если он действительно другой.
- **Проверка полноты — по всем языкам.** Однажды подсчёт по кириллице «не нашёл» английских стихов,
  а их было 36. Считать тексты по любому алфавиту.

### 2.3 Дубли [проверено]

- Точный дубль — md5 нормализованного текста.
- Почти-дубль — Jaccard по 5-словным шинглам ≥ 0,9 или вложение одного текста в другой.
  Точный хеш пропустил 11 пар эссе, шинглы нашли.
- Отдельно проверить дубль «полная редакция + фрагмент» (у Бродского — «Набережная неисцелимых»).

### 2.4 Классификация [проверено]

Для каждого текста:

- `lang` — по доле латиницы и кириллицы;
- `genre` — стихи, если ≥ 85% непустых строк короче 75 знаков и строк ≥ 4; иначе проза.
  Для прозаика нужны ещё пьесы (реплики с именем персонажа в начале) и письма (обращение + дата/подпись)
  **[не проверено]**;
- `author` — own / translation (переводы чужих текстов) / about (интервью, биография) /
  other (чужие тексты, приложенные к эссе).

### 2.5 Датировка [проверено]

- Год берётся из **авторской** даты в последних строках текста: короткая строка (≤ 8 слов)
  с годом в допустимом диапазоне жизни.
- Пометы публикатора («Текст по публикации… 1997», «Источник…») исключаются регулярным выражением
  до поиска года. Ошибка на этом месте дала «Акростиху» 1997 год.
- Проверка: сравнить годы с периодами источника. После исправления расхождений стало 6 из 517
  датированных стихов, до исправления было 25.
- Недатированные тексты ставятся в конец своего периода и на графиках рисуются полыми.

### 2.6 Очистка перед подсчётами [проверено]

Убрать из анализируемого текста: редакторские примечания, строки-даты, римские цифры частей,
абзацы комментариев внутри стихотворной записи (строка длиннее 28 слов в стихах), посвящения
оставить (в них имена).

### 2.7 Книги (EPUB) [проверено]

- EPUB3 + NCX вручную через `zipfile`: `mimetype` первым и без сжатия.
- Оглавление в несколько уровней: раздел → период → текст.
- Страницы разделов резервируются в spine до текстов, иначе EPUBCheck даёт NAV-011.
- Проверка: EPUBCheck 5.x без ошибок.

### 2.8 Тематический подкорпус (у Бродского — Венеция) [проверено]

1. Словарь маркеров: леммы и топонимы темы.
2. Каждый кандидат читается в контексте моделью; вердикт записывается в код со строкой-обоснованием.
3. Итог сверяется с внешним перечнем (исследовательская статья, библиография).
   Если внешний перечень находит тексты, которых нет, правило расширяется.
4. Заказчик видит состав и может возразить («всего 13 — не может быть»): проверить,
   не ошибся ли отбор, и показать список с причинами.

## 3. Лингвистическая разметка

### 3.1 Русский [проверено]

- `pymorphy3`, первый разбор, без снятия омонимии. Это даёт систематические ошибки, которые
  нужно знать заранее (раздел 7).
- Служебные части речи (предлоги, союзы, частицы, местоимения) и имена собственные исключаются
  из списков «частых слов».
- Слоги = число гласных. Для русского это точная мера длины строки.

### 3.2 Ударения и метр, русский стих [проверено]

- `ruaccent` (модель turbo3.1, словарь, омографы) в **отдельном** окружении: `transformers<5`
  (в 5.x ошибка `token_type_ids`), свой `numpy`. Возобновляемый прогон, результат в JSON.
- Ошибки модели в редких словах и топонимах («Н**о**ренская») переходят в метр и рифму —
  написать это в методике.

### 3.3 Другие языки [не проверено]

| Язык | Морфология | Стих |
|---|---|---|
| Французский (Гари) | spaCy `fr_core_news_sm` (CPU) или stanza | слог французского стиха считается по правилам немого e; для прозы не нужно |
| Английский | spaCy `en_core_web_sm` | ударения — словарь CMU (`pronouncing`) |
| Смешанный корпус | разметка по языку каждого текста | метрики не смешивать между языками |

Для автора, писавшего на двух языках (Гари: французский и английский; Бродский: русский и английский),
каждый язык — отдельный подкорпус со своим разделом.

## 4. Измерения

Каждое измерение ниже описано так: **что**, **как**, **пороги**, **как сказать читателю**.
Пороги — те, что применялись к Бродскому; для другого автора их можно менять, но тогда
изменение пишется в методике.

### 4.1 Обзор корпуса [проверено]

Число текстов по жанрам и языкам, слов, разных слов; сколько исключено и почему
(переводы, интервью, чужие тексты). Тексты по годам, пики — с биографическими пометками
(у Бродского: 1964 ссылка, 1972 эмиграция, 1987 Нобелевская премия).

Рост словаря (кривая Хипса): сколько разных слов встретилось, если читать тексты по порядку.

### 4.2 Длина [проверено]

- Стихи: слогов в строке — медиана и 25–75% по годам и периодам; распределение по периодам (ридж);
  строк в стихотворении.
- Проза **[не проверено]**: слов в предложении, предложений в абзаце, длина текста; самые длинные
  предложения с цитатой.
- Читателю: «типичная строка (медиана: половина строк короче, половина длиннее)».

### 4.3 Размер (стих) [проверено]

- Классический размер (ямб, хорей, дактиль, амфибрахий, анапест, с числом стоп): ≥ 85% строк
  не ставят ударение многосложного слова на слабое место. Пропуск ударения на сильном месте допустим.
- Иначе по промежуткам между ударениями (p1, p2, p3 — доли промежутков в 1, 2, 3 слога):
  - дольник, если p1+p2 ≥ 0,75, min(p1, p2) ≥ 0,15, p3 < 0,12 и промежутков ≥ 5 слогов ≤ 5%;
  - тактовик, если p1+p2+p3 ≥ 0,85 и p3 ≥ 0,12;
  - иначе свободный стих.
- Первая версия (без этого правила) приписала 62% строк 1973–84 годов свободному стиху — ложно.
- Читателю: каждый размер показан на строке самого автора, ударные слоги выделены, под строкой
  схема «та-ТА-та-ТА».

### 4.4 Рифма (стих) [проверено]

- Окончание — от последнего ударного гласного до конца строки, с оглушением конечных согласных
  и редукцией безударных.
- Рифма ищется в окне 4 строк, не дальше соседней строфы.
- Типы: точная (полное совпадение; для открытых мужских — ещё общая согласная перед ударным),
  неточная (отличается одна согласная), созвучие (ударный гласный + последний звук).
- Слова короче 3 букв не рифмуются; составная рифма — два последних слова строки.
- Схемы четверостиший: АБАБ, ААББ, АББА.
- Интерактив «словарь рифм»: слово → с чем автор его рифмовал.
- Ошибки, которые уже были: «ночь — бой», «милая — и». Правило ужесточено; остаточные ошибки
  («ночь — денег») упомянуть в методике.

### 4.5 Строфа, фраза, перенос [проверено]

Строфы по числу строк (тепловая карта по периодам); доля строк, кончающихся предлогом, союзом,
частицей; строк без знака в конце; длина фразы в строках; фраза, переходящая в следующую строфу.

### 4.6 Звук [проверено]

- Аллитерация: ≥ 3 **разных** слова строки на один согласный. Повтор одного слова («Сказал» ×4)
  не считается.
- Сравнение со случайным: те же слова периода перемешиваются и собираются в строки той же длины,
  20 повторов. Вывод зависит от отношения: ≥ 1,15 — «чаще случайного», ≤ 0,9 — «реже»,
  между — «не систематический приём». Не округлять в пользу красивого вывода.

### 4.7 Словарь [проверено]

- Частые существительные, глаголы, прилагательные — топ-20, на 10 000 слов, стихи и проза отдельно.
- Разнообразие: доля разных слов в каждых 500 подряд (MATTR, но в тексте так не называть).
- Закон Ципфа — картинкой.
- «Слова эпох»: log-odds с информативным априором Дирихле (Monroe et al., 2008), слово в периоде
  ≥ 5 раз, имена собственные исключены; топ-20 на период; сравнение двух периодов.
- Словоискатель: индекс начальных форм (в стихах ≥ 2 раз или в прозе ≥ 5): частота по периодам,
  список текстов, 2 примера, близкие слова.
- Карта словаря: 260 частых слов; окно 5 слов → PPMI → SVD (100 измерений) → t-SNE на numpy;
  группы — k-средних. Интерактив: периоды (слово растёт и краснеет, если в периоде
  ≥ 1,5 раза чаще среднего и ≥ 6 употреблений), кнопка «Играть», соседи линиями.

### 4.8 Смысловые поля, эпитеты, сравнения [проверено]

- 20 полей × 20 слов, поля не пересекаются; частота на 1000 слов по периодам; режим «отклонение»
  (каждое поле относительно себя).
- Эпитет: согласованное прилагательное перед существительным, устойчивые обороты исключены.
- Сравнения: «как», «словно», «будто», «точно».
- Родительные формулы: существительное + существительное в родительном («часть речи»).

### 4.9 Стиль и его переломы [проверено]

- Для каждого года с ≥ 6 текстами — вектор из 12 мер формы.
- Точки перелома — жадная бинарная сегментация (алгоритму не сообщают биографию).
- Словарное расстояние между годами — Delta Барроуза по 100 частым словам.
- Группы текстов без дат — k-средних; совпадение с периодами — скорректированный индекс Рэнда
  с нулевой моделью (95-й перцентиль перемешанных меток).
- Читателю: «Алгоритм сам искал годы, где стиль меняется резче всего; ему не сообщали дат».

### 4.10 Грамматика и пунктуация [проверено]

Существительных на глагол, причастия и деепричастия, местоимения (у каждой мини-диаграммы своя
шкала), знаки на 1000 слов в стихах и прозе.

### 4.11 Мир автора: персонажи, места, вещи [проверено]

**Имена собственные.**

- Кандидат — слово с заглавной внутри фразы. В стихах с заглавной в начале каждой строки
  начало строки не считается.
- Лемма считается именем, если ≥ 70% её употреблений внутри фразы — с заглавной и таких ≥ 2.
- Тип: метки pymorphy (`Name/Surn/Patr` — лицо, `Geox` — место), затем соседи. Рядом с именем
  или инициалом — лицо; после предлога «в, на, из, до, около…» — место.
- Имя перед фамилией и отчество после имени не считаются отдельными людьми.
- Явный список исправлений (писать в методике): склейка написаний (Харди/Гарди, Уистан → Оден),
  исключения (праздники, названия книг, сам автор), принудительный тип (Гомер — лицо).

**Сеть персонажей.**

- Связь — оба названы в одной строфе или одном абзаце. Стихи без пустых строк режутся по 12 строк.
- В сети 120 самых упоминаемых по числу текстов, остальные — в поиске.
- Круги имён — спектральная кластеризация + k-средних.
- Раскладка «островами»: круг — остров на кольце, внутри самые частые в центре. Силовая раскладка
  давала комок в центре и одиночек по краям.

**Рейтинги — по числу текстов, а не упоминаний.** По упоминаниям персонаж одной пьесы
(Публий — 493 упоминания) обгоняет всех.

**Вещи: места без названий, транспорт, еда, напитки.** Словари лемм по группам.

- Слово с частым другим значением в словарь не входит: «виски» — височки, «паром» — пар,
  «угол», «камера», «рынок», «буфет».
- Частица «чай» («на улице, чай, не Франция») отсекается по запятым вокруг.
- Незнакомые pymorphy слова получают выдуманную лемму («граппа» → «грапп»). Ключ словаря
  строится так же, как лемма токена.
- **Аудит по сырому тексту обязателен:** для каждого слова словаря искать основу в сыром тексте
  и сравнивать с засчитанным. Всё, что «по тексту больше, чем засчитано», просмотреть глазами
  модели. На этом аудите нашлись и «граппа», и «виски».
- Поиск пропусков: существительные рядом с глаголами «пить / есть / ехать», незнакомые словарю
  слова рядом со «стаканом», «бутылкой», «ужином».
- Числа — нижняя оценка, в тексте так и написать. Показывать «редких гостей» (1–2 употребления)
  с цитатой: читателю это интереснее всего.

### 4.12 Проза: что добавить для прозаика [не проверено]

| Мера | Как | Зачем читателю |
|---|---|---|

## 5. Самопроверка без ручной разметки

1. **Режимы `--qa`, `--audit`, `--ctx` в каждом скрипте:** печатать топ результатов с контекстами,
   пропуски по сырому тексту и контексты выбранных слов. Модель читает вывод и исправляет правила.
2. **Сверка с внешним:** периоды сайта против найденных дат; тематический подкорпус против
   внешнего перечня; число текстов против оглавления собрания.
3. **Базовая линия для любого «чаще»:** случайная перестановка, нулевая модель, проза того же
   автора как фон.
4. **Проверка вывода фразой:** каждая фраза-вывод в отчёте собирается из данных шаблоном с
   условиями (у «Мифов и фактов» вердикт выбирается порогом: «подтверждается / отчасти / не
   подтверждается / наоборот»), а не пишется вручную под ожидаемый ответ.
5. **Ошибки признавать в методике:** что модель ударений путает, что омонимы не различаются,
   что словари неполны.

## 6. Отчёт (интерактивный HTML)

### 6.1 Структура [проверено]

Сплошная лента с верхней полосой частей и боковым указателем разделов (вкладки-экраны
заказчику не понравились: «экраны есть, а прокрутка всё равно»).

1. **Шапка**: название, вводный абзац с главным выводом, цифры корпуса, фирменная визуализация
   всего корпуса (у Бродского — каждый стих листом, каждая строка штрихом длиной в слоги;
   поиск слова подсвечивает листы; клик открывает карточку).
2. **Обзор**: «Главное коротко» (6 цифр «было → стало»), «Мифы и факты» (вердикт порогом),
   хронология.
3. **Форма**: для поэта — строка, размер, рифма, строфа, звук, атлас стихотворений;
   для прозаика — предложение, абзац, диалог, начала и концовки, атлас произведений.
4. **Слова**: частые слова, словоискатель, карта словаря, слова эпох, эпитеты, темы.
5. **Стиль**: грамматика, пунктуация, цвета, переломы.
6. **Мир автора**: персонажи (сеть), места, транспорт, еда, напитки (и другие «полки» по автору:
   у Чехова вероятны болезни и лекарства, деньги, чины — **[не проверено]**).
7. **Спецтема** (Венеция).
8. **Проза / второй язык / рекорды / методика**.

### 6.2 Интерактивы, которые окупились [проверено]

Атлас с карточкой текста (метрики плитками, строение текста, характерные слова, ссылка на текст
в источнике); словоискатель; словарь рифм; карта словаря с периодами и соседями; сеть персонажей
с карточкой, цитатами и соседями; полки вещей с карточкой слова; «Таблица данных» под графиком.

Каждая карточка открывается сразу в заполненном состоянии (пример: «Лагуна», «стекло», «Рим»).

### 6.3 Оформление [проверено на отзывах заказчика]

- Язык простой. Не писать «лемма», «MATTR», «синтагма», «вещный», «назывной», «keyness».
  Писать «слово во всех формах», «разных слов на каждые 500», «фраза», «сила отличия».
- Тёплая палитра; не холодные сине-фиолетовые. Рукописные шрифты — нет («пошлость»).
- Категориальная палитра проходит валидатор (`dataviz`: `validate_palette.js --mode light|dark`)
  для обеих тем. Цвет несёт группу, текст — всегда цветом текста.
- Обе темы через токены `:root`; тёмная — свои значения, а не инверсия.
- Шрифты — Google Fonts, подключение асинхронное.

### 6.4 Техника [проверено]

- Один HTML-файл, без библиотек: SVG и canvas вручную.
- Данные — в `<script type="application/json">`, подставляются сборщиком (`build_report.py`).
  Экранировать `</` в JSON.
- **Отрисовка порциями:** очередь `chart(fn, box)` → `pump` по 12 мс. Без этого страница
  «не открывалась». Кеш CSS-токенов, перерисовка по смене темы и ширины.
- Шаблон собирается патчером из предыдущей версии, старая версия остаётся воспроизводимой.
- Размер: ~3 МБ для 633 текстов — нормально.

### 6.5 Проверка перед публикацией [проверено]

1. Все `id`, к которым обращается JS, есть в разметке (скрипт-сверка). Один пропавший `id`
   в верхнеуровневом коде роняет всю страницу.
2. Headless Chrome: консоль без ошибок, число отрисованных графиков.
3. Снимки: десктоп светлая и тёмная, телефон 500 px. В headless тема задаётся атрибутом
   `data-theme` в обёртке: флаг `preferredColorScheme` игнорируется.
4. Публикация как артефакт; новая версия — новый файл и новый артефакт, если заказчик
   просит «новую версию, старую не трогать».
