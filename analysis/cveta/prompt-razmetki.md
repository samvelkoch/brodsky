# Задача: цветовая разметка стихов Бродского по строкам

Входной файл: `in2/cXX.txt` (см. свой номер; выход — `out2/cXX.jsonl`). Формат: заголовок `### POEM <pid> | <название> | <год>`, затем непустые строки стихотворения с номерами `<idx>\t<строка>`.

Для КАЖДОГО стихотворения прочитай его ЦЕЛИКОМ (контекст важен), затем для каждой строки реши, вызывает ли она зрительный цвет. Строки без зрительного цвета пропускай, но НЕ пропускай строки, где есть предмет или время суток с цветом.
ОБЯЗАТЕЛЬНО размечай (это не «пустые» строки): ночь/полночь/ночью/сумерки/вечер → ночной синий (o); снег/сугроб/иней → белый; огонь/огни/пламя → оранжевый (уличные огни, фонари, окна → жёлтый/медовый); кровь → красный/багровый; луна/звезда → серебряный; туман/мгла/дым → тёмно-серый/серый; листья, трава → зелёный (осенние листья → охра/жёлтый); море, небо, вода → по контексту; камень, гранит, асфальт → серый.
Ориентир плотности: в пилоте у лирики цвет получили 35–60% строк. Если в стихотворении у тебя меньше ~20% — ты, скорее всего, пропускаешь. Читай и размечай КАЖДУЮ строку, кусками не больше ~150 строк за шаг, не пробегай глазами.

## Палитра (только эти ключи)
белый, бледный (слоновая кость, бледность, мрамор), серебряный (лунный, рыбья чешуя, амальгама, металл-блеск), серый, тёмно-серый (мгла, свинец, графит, железо), чёрный,
ночной синий (ночь, сумерки, вечерняя тоска), тёмно-синий, синий, голубой, бирюзовый (лагуна, морская вода),
зелёный, тёмно-зелёный (хвоя, ель), оливковый (болото, тина),
жёлтый (фонари, лимон), медовый (тёплый свет ламп, янтарь, бронза), золотой, охра (песок, хлеб, степь, халва), оранжевый (огонь, пламя, костёр, медь),
кирпичный (кирпич, ржавчина, терракота), красный, багровый (кровь тёмная, закат густой), розовый (заря, румянец), лиловый (сирень, фиалка), коричневый (дерево, глина, грязь, кора).

## Источник цвета (src)
- `n` — цвет НАЗВАН словом прямо (белый, чернеть, синева, седой, кирпичный, золотой, желтеть…). Если цветовое слово стоит в идиоме без зрительного смысла («красный угол», «белые стихи», «чёрный ход»), всё равно `n`, но conf=1 и в basis допиши «идиома».
- `o` — цвет ПРЕДМЕТА/явления в строке (снег→белый, огонь→оранжевый, кровь→красный, трава→зелёный, море→по контексту: у Бродского часто серое; небо→по контексту; ночь→ночной синий; фонарь→жёлтый).
- `m` — НАСТРОЕНИЕ/атмосфера, когда строка явно окрашена, но предмета с цветом нет (тоска в ночном городе→ночной синий; горе→тёмно-серый). Используй экономно.

Если в строке несколько цветов — выбери доминирующий для строки (тот, что зритель увидел бы первым), учитывая контекст стихотворения.

## Уверенность (conf)
3 — назван прямо; 2 — устойчивый цвет предмета, ясно из контекста; 1 — догадка, настроение, идиома.

## Не размечай
Посвящения, даты, номера частей (I, II…), эпиграфы-ссылки, примечания редактора («С. В.», «прим.», «Датировано…»), сноски.

## Примеры (из пилота)
- «среди кирпичного надсада» → ["кирпичный","n","кирпичного",3]
- «ночной фонарик нелюдимый» → ["жёлтый","o","фонарик",2]
- «Плывет в тоске необъяснимой» (ночная Москва) → ["ночной синий","m","тоска, ночь",1]
- «дрожат снежинки на вагоне» → ["белый","o","снежинки",2]
- «и льется мед огней вечерних» → ["медовый","o","мед огней",2]
- «За золотой чешуей всплывших в канале окон» → ["золотой","n","золотой чешуей",3]
- «Как сирокко - лагуну» → ["бирюзовый","o","лагуна",2]
- «Но пока мне рот не забили глиной» → ["коричневый","o","глина",2]
- «над головой своих любимых» → (пусто)

## Выход
Файл `out2/bXX.jsonl (или путь, указанный в задании)`: ровно одна JSON-строка на каждое стихотворение входного файла (в том же порядке), даже если цветных строк нет:
`{"pid": 73, "c": {"2": ["кирпичный","n","кирпичного",3], "5": ["жёлтый","o","фонарик",2]}}`
Ключи — номера строк (строкой). basis — 1–3 слова из строки, на которые опирается цвет.

Пиши результат ПОСТЕПЕННО: после каждых нескольких стихотворений дописывай строки в файл через Bash (`cat >> out2/bXX.jsonl (или путь, указанный в задании) <<'EOF' ... EOF`), не держи всё до конца. Читай вход частями (Read с offset/limit), если файл большой.
В конце проверь: `python3 -c` что каждая строка файла — валидный JSON, ключи палитры только из списка, и число строк равно числу `### POEM` во входе. Исправь ошибки.
Не публикуй и не копируй тексты стихов никуда, кроме своего out-файла (там только basis). Не используй инструменты mcp__hearthbot__.
